## Задача

Даны α, буква x и натуральное число k. Вывести длину кратчайшего слова из языка L, содержащего подслово x^k.

## Общая идея решения

Чтобы найти минимальную длину слова, удовлетворяющего регулярному выражению, программа:

1. Парсит регулярное выражение α.
2. Строит недетерминированный конечный автомат по алгоритму Томпсона.
3. Запускает BFS по состояниям автомата, где каждое состояние расширено счётчиком подряд прочитанных символов x.
4. Останавливается при первом достижении принимающего состояния, в котором было прочитано подряд k символов x.

## Построение постфиксной формы

Чтобы упрощённо построить недетерминированный конечный автомат, регулярка переводится в постфиксную форму:

1. Вставляются операторы конкатенации . явно.

2. Используется алгоритм сортировочной станции:
   - операторы *, . , | имеют приоритеты 3, 2, 1 соответственно,
   - '*' применяется к предыдущему выражению.

В результате получаем строку в постфиксной записи, где порядок операций однозначный.

## Построение НКА по Томпсону
Дальше строится НКА по Томпсону:
- При "a" переход start -> end по символу a.
- При "AB" соединяем A.end -> B.start epsilon-переходом

epsilon-переходы означают, что автомат может переходить без потребления символа

После построения:
- nfa.start - начальное состояние,
- nfa.accept - принимающее состояние.

---

Перед любым шагом символьного перехода нужно знать все состояния, достижимые по эпсилон-переходам без чтения символа.

Функция epsilon_closure_from_set():
- принимает множество активных состояний
- добавляет к нему все состояния, достижимые по эпсилон.

---

Функция move_on_symbol():

1. Для всех состояний в set проверяет, куда можно перейти по символу c.
2. После этого берёт эпсилон-замыкание новых состояний

## BFS по состояниям автомата

Для поиска минимальной длины слова используется поиск в ширину.

Каждая вершина BFS описывается парой current_states, count_x. 

current_states - множество активных вершин автомата,
count_x - сколько подряд символов x уже прочитано

 стартуем с эпсилон-замыкания стартового состояния, count_x = 0, длина = 0

Далее на каждом шаге:

1. Для каждой буквы a из алфавита выполняем move_on_symbol()
2. Если a == x, то new_count_x = min(k, count_x + 1),
   иначе new_count_x = 0
3. Если множество новых состояний непустое, и оно включает accept-состояние автомата, и new_count_x == k, значит найдено кратчайшее слово, длина = текущая длина + 1.
4. Иначе - добавляем это состояние в очередь BFS, если оно ещё не посещено

---

Чтобы не заходить в одинаковые комбинации снова, используется unordered_set<string> с уникальным ключом

key = [битовая маска состояний автомата] + [count_x]

Это гарантирует уникальность (учитывается и позиция в автомате, и прогресс в подсловах x^k).

## Условие завершения

Поиск завершается, когда впервые достигнуто состояние has_accept(current_set) && count_x == k

Возвращается длина слова на этом уровне BFS. Если очередь опустела - значит, подходящего слова нет, выводится -1.
